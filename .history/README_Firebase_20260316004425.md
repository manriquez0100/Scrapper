# 🔥 Integración Firebase con BuscaLibre Scraper

## Descripción
Sistema completo para extraer información de libros desde BuscaLibre.com.mx y guardarla automáticamente en Firebase Firestore.

## 📋 Características Firebase
- ✅ Subida automática de datos de libros a Firestore
- ✅ Estructura de datos compatible con tu base de datos existente
- ✅ Configuración fácil de credenciales
- ✅ Manejo de errores y reintentos
- ✅ Campos configurables según la estructura de tu DB

## 🚀 Configuración Rápida

### 1. Instalar Dependencias
```bash
pip install -r requirements.txt
```

### 2. Configurar Firebase
```bash
python configurar_firebase.py
```

### 3. Ejecutar Scraper con Firebase
```bash
python buscalibre_con_firebase.py
```

## 📁 Archivos Principales

### Scripts de Scraping
- `buscalibre_con_firebase.py` - Scraper principal con integración Firebase
- `firebase_uploader.py` - Módulo para subir datos a Firestore
- `configurar_firebase.py` - Asistente de configuración de credenciales

### Configuración
- `firebase_config.py` - Credenciales de Firebase (se genera automáticamente)
- `requirements.txt` - Dependencias del proyecto

## 🔧 Configuración Manual de Firebase

### Paso 1: Obtener Credenciales
1. Ve a [Firebase Console](https://console.firebase.google.com)
2. Selecciona tu proyecto
3. Ve a **Configuración del proyecto** > **Cuentas de servicio**
4. Haz clic en **Generar nueva clave privada**
5. Descarga el archivo JSON

### Paso 2: Configurar Credenciales
Opción A: Usar el configurador automático
```bash
python configurar_firebase.py
```

Opción B: Manual - Guarda el archivo JSON como `firebase-credentials.json`

Opción C: Edita `firebase_config.py` con tus credenciales

  "disponible": "true",

## ⚙️ Configuración del Scraper

En `buscalibre_con_firebase.py` puedes modificar:

```python
# Configuración principal
search_term = "HISTORIA DE MEXICO"  # Término de búsqueda
NUMERO_PRODUCTOS = 5               # Cantidad de libros
ganancia_envio = 100              # Ganancia por envío

# Características
DESCARGAR_IMAGENES = True         # Descargar imágenes
ABRIR_ENLACES = True             # Abrir páginas individuales
NAVEGAR_A_DETALLE = True         # Extraer info detallada
SUBIR_A_FIREBASE = True          # Subir a Firebase
```

## 🔥 Uso de Firebase Uploader

### Subir desde archivo de texto
```python
from firebase_uploader import FirebaseUploader

uploader = FirebaseUploader()
uploader.upload_books_from_file(
    "busquedas/book_images_HISTORIA_DE_MEXICO/libros_HISTORIA_DE_MEXICO.txt",
    "HISTORIA DE MEXICO"
)
```

### Subir datos directamente
```python
from firebase_uploader import FirebaseUploader

uploader = FirebaseUploader()

libro_data = {
    'nombre': 'Título del libro',
    'autor': 'Autor del libro',
    'precio_numerico': 659,
    'url_libro': 'https://...',
    'url_imagen': 'https://...'
}

uploader.upload_book(libro_data, "términoq de búsqueda")
```

## 🛠️ Solución de Problemas

### Error de Autenticación
```
❌ Error conectando a Firebase: [403] Permission denied
```
**Solución:** Verifica que las credenciales sean correctas y que la cuenta de servicio tenga permisos de escritura en Firestore.

### Error de Proyecto
```
❌ Error: Project not found
```
**Solución:** Verifica que el `project_id` en las credenciales coincida con tu proyecto de Firebase.

### Firebase Admin no instalado
```
❌ ModuleNotFoundError: No module named 'firebase_admin'
```
**Solución:** 
```bash
pip install firebase-admin
```

## 📈 Funcionalidades Avanzadas

### Configuración de Colección
Puedes cambiar la colección de destino en `firebase_config.py`:
```python
COLLECTION_NAME = "mi_coleccion_de_libros"
```

### Filtros Personalizados
Modifica `extract_book_info()` en `firebase_uploader.py` para agregar campos personalizados.

### Reintentos Automáticos
El sistema incluye manejo automático de errores y reintentos para conexiones inestables.

## 🔒 Seguridad

- ⚠️ **NUNCA** subas `firebase_config.py` a repositorios públicos
- ✅ Añade `firebase_config.py` y `firebase-credentials.json` a tu `.gitignore`
- ✅ Usa cuentas de servicio con permisos mínimos necesarios
- ✅ Rota las credenciales periódicamente

## 📞 Soporte

Si tienes problemas:
1. Ejecuta `python configurar_firebase.py` y usa la opción "Probar conexión"
2. Verifica que tu proyecto de Firebase tenga Firestore habilitado
3. Revisa que la cuenta de servicio tenga rol "Editor de Firestore" o superior
